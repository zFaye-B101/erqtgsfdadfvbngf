# R2 课堂统计补充

基于已归档结果的后处理，不是新训练轮次。2026-10-13 用户授权验证后共享统计方法、结果和复现脚本；个人 Methods 正文不包含在此目录。

## 依据与口径

唯一统计方法依据为 COMP90051 正式 Lecture 15: Cross-Validation：第18页方差定义，第26–30页 Student's t 比较及例子，第31页均值误差条，第32页总结。讲义由组员从课程平台读取，本次不公开转载课件或录播。没有引入外部修正检验文献。

同算法、同条件比较 F4/F4.1/F4.2 与 F3，各有10个外层折。按课件取方差分母 m、自由度向上取整：

\[
t=\frac{(\bar M_1-\bar M_2)\sqrt m}{\sqrt{v_1+v_2}},\quad
\nu=\left\lceil\frac{(v_1+v_2)^2(m-1)}{v_1^2+v_2^2}\right\rceil.
\]

单侧 alpha=0.05；FPR 检验全局高于局部，AUC 检验局部高于全局，TPR 检验全局高于局部以检查召回损失。课件方法使用两组各自的方差，**不是配对差值 t 检验**。数据仍按同折对齐，配对差值另存为描述性证据。

主口径是原95%校准目标、全部负例；90%及两个负例子集单列补充。完整保留全部810项比较，不只保存 p<0.05 的结果。分析在已看过实验结果后开展，属事后探索；p值为未作多重比较校正的单项近似值。CV折共享训练商品，独立性不成立，课堂录播也提醒这一限制。不将多项拒绝解释为整体确认性结论。TPR下降未显著不能证明等效或非劣效。

原描述性接受标准（FPR均值下降且至少8/10折改善、TPR均值下降不超过1个百分点）不变；该标准与t比较分开解释。现有图的样本SD不改名为置信区间，新表的均值t区间为单独的逐项近似区间。

## 主结果

95%校准目标、全部负例、LR，差值为F4.2减F3，FPR/TPR单位为百分点。

| 条件 | FPR差值 | FPR下降p | TPR差值 | AUC差值 |
| --- | ---: | ---: | ---: | ---: |
| clean | -7.53 | 0.0061 | -0.68 | +0.0187 |
| occlusion25 | -6.07 | 0.0401 | -0.63 | +0.0181 |
| noise005 | -6.02 | 0.0405 | -0.57 | +0.0134 |
| blur15 | -7.11 | 0.0105 | -0.99 | +0.0221 |
| rotation15 | -4.87 | 0.0522 | -0.47 | +0.0234 |

- F4.2-LR：FPR四条件达到单项0.05标准，旋转未达到；AUC五条件达到。
- F4.2-SVM/SupCon：没有FPR比较达到该标准；AUC分别为五/四条件，SupCon噪声例外。
- F4/F4.1：没有FPR或AUC改善比较达到该标准，不代表证明没有效果。
- 主口径45项TPR下降比较均未拒绝零假设，不代表召回等效。
- 90%目标另存：F4.2-LR仅干净/模糊的FPR比较达到单项标准。SupCon噪声FPR下降p=0.0231，同时TPR下降p=0.0280，不能只强调误报改善。95/90的AUC相同，不重复计为独立证据。

## 复现

在已有 NumPy、SciPy 的 Python 环境中，从仓库根目录运行（不需要SOP数据、GPU、模型权重或训练）：

```sh
python docs/experiments/2026-10-13-course-statistics/analyse.py
python docs/experiments/2026-10-13-course-statistics/validate.py
```

脚本读取相邻的 [R2归档](../2026-10-13-R2-local-features/README.md) 和 [90%归档](../2026-10-13-R1-R2-recall90/README.md)，仅重新生成本目录CSV/JSON；不修改源归档。路径相对仓库自动定位，无本机路径配置。已验证环境的SciPy版本写在verification.json中；脚本使用标准SciPy分布接口进行独立数值核对，不调用现成ttest函数代替课件公式。
