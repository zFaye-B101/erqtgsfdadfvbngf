## R2 事先确定的判断标准（用户 2026-10-12 确认，运行前锁定）

- 比较对象：F4.1、F4.2 分别与同骨干全局基准 F3（以及 F4）比较；每个算法（LR、SVM、SupCon）、每个条件（原图、遮挡、噪声、模糊、旋转）单独判断，均用 10 个外层折的配对差值。
- **减少误匹配**：FPR 配对差值均值 < 0，且至少 8/10 个折方向一致。

- 两条同时满足才称“在该条件下减少误匹配且保持匹配”；同时报告 AUC 差值与折间标准差。这是描述性判断，不是显著性检验；结果不支持时同样完整报告。
- **负例子集**：以全部负例和随机负例为主；困难负例子集只作补充，并注明其按“干净图、仅内容区域 HSV48”选择，会系统性低估颜色类特征（见 [F5 结果](experiments/2026-10-12-R1-f5-padding/README.md)）。

## 已选择的方向

For unseen products, can adding local visual features reduce false matches between visually similar products under occlusion, noise, blur, and rotation while maintaining same-product matching performance?

中文定稿（2026-10-12 用户确认）：对训练中未见过的商品，加入局部视觉特征，能否在遮挡、噪声、模糊和旋转条件下减少外观相似商品之间的误匹配，同时保持同商品匹配能力？

- 数据：Stanford Online Products (SOP)。`class_id` 是商品标注 ID；`super_class_id` 是大类。
- 比较：正则化 Logistic Regression、RBF SVM、SupCon-based matching。
- SupCon 训练使用商品 ID，使同商品表示靠近；最终用相似度和阈值判断两图是否同商品。不是用训练商品分类头直接预测未见商品。
- 早期 LightGBM、TabM、UCI HAR、SCARF 文件仅保留研究历史。

## 特征比较与实验约束

依据 [Project Sections 2.a-g 与 3](../materials/official/Project.md)，研究问题不只是比较三个算法的分数。主比较应回答“加入局部信息后，误匹配是否减少，而且没有靠降低同商品检出率换取该改善”。

| 比较 | 要检验的解释 | 必须控制或披露 |
| --- | --- | --- |
| ResNet18 Global512 与 Global+Local2560 | 局部空间信息是否补充整体外观 | 同一骨干/权重、图像、商品折、图片对、调参预算；维数及正则化差异 |
| HSV48 与 HSV+空间梯度192 | 颜色之外的空间/边缘信息是否有帮助 | 两者不是CNN局部特征的直接替代；颜色困难负例选择可能偏向颜色特征 |
| 含填边与仅内容区域的传统特征 | 收益是否来自填边或长宽比线索 | 同一图像来源和干扰条件；这是预处理对照，不算第四种算法 |
| Clean 与遮挡/噪声/模糊/旋转 | 哪种可见信息丢失最影响匹配 | 同一query/reference图片对；保持已校准阈值，联合查看TPR与FPR |

F1–F5 已有三算法结果，当前新增比较为 R2 的 F3/F4/F4.1/F4.2。不能因为某特征维数大、模型新就预设性能更好。只有单一遮挡强度时，只能回答该强度下的问题；多强度曲线仍未运行或批准。

### 论文理解与实现对照

每种方法说明输入、学习目标、输出和匹配决策。SupCon重点核对论文损失、正/负例如何定义、温度的作用、编码器与投影头的不同用途；用原论文和作者实现核对，而不把“下载预训练权重”当作已实现SupCon。报告清楚区分冻结ResNet的外部预训练与SOP训练折内学习，列明本项目对原方法的适配及未复现部分。

### 每个外层折的实际数据流

1. 先按商品划分外层训练与测试；从外层训练中再预留独立校准商品。
2. 仅在剩余拟合商品上运行至少3折内层搜索；归一化及可训练表示也在相应训练折拟合。记录候选值、内层分数、边界扩展和选择频次。
3. 按内层选出的参数，在拟合商品上训练最终模型；用校准商品定阈值。当前v3在这一步后不再重训，避免把阈值移植到另一个模型。
4. 最后一次性评价该折外层测试的干净和扰动图片对，保存分数、标签、阈值、配对身份及结果。不得用外层测试决定C、温度、阈值或挑选最好看的设置。
5. 汇总相同外层折上的方法/特征配对差异及波动。开发使用过的折或数据不再宣称为完全未触碰的最终测试；官方holdout继续关闭，待协议锁定后再决定是否需要一次补充评估。

至少10个外层折、每算法至少一个超参数且至少三个候选、手写CV/搜索/指标仍是正式要求。2/2折smoke只用于检查程序，不能进入正式报告主结果。

## 历史开发诊断（截至 3c033c2，不代表最新实现缺失）

### CNN小样本与当时传统流程

历史证据见 [CNN+LR三轮开发结果](experiments/2026-10-11-lr-feature-pilot.md) 和 [009a241进度互评](reviews/2026-10-11_009a241_python-progress_codex.md)。当时.py只有HSV48/HSV+空间梯度192的传统LR/SVM，终端CNN测试尚未整合；现在共享实现已有CNN和SupCon，但没有据此重算旧分数。

全局与局部两个候选均保留。种子45/46/47两轮C搜索配对哈希一致；扩展至[0.0001,0.001,0.01,0.1]后遮挡FPR均值从Global的0.3194降到G+L的0.2639，平均TPR同为0.7583，但逐种子TPR不同且AUC差仅+0.0059，尚无稳定优越性结论。这是开发诊断，不替代正式nested CV。

旧传统流程用95%目标召回率、1:2正负例、HSV困难负例及内容区域灰色遮挡；CNN小试用80%、1:1随机负例及中心裁剪画布均值色遮挡，并进行逐区域L2归一化。当前共享CNN使用填边输入且不做同样的逐区域L2归一化，因此不能直接比较或复用两边分数。

- [冻结特征开发诊断](experiments/2026-10-11-feature-diagnostics.md)及[LR训练诊断](experiments/2026-10-11-lr-feature-pilot.md)分开归档；有运行数值但缺完整可复现包，没有正式三模型或嵌套评估结果。
- 新增的 `01_SOP_Preprocessing.ipynb` 当前会生成 192 维 HSV+空间 HOG 逐图特征；`sop_features.py` 提供 SIFT 图片对特征函数。这是可复用的初步预处理代码，不取代下列待验证的特征比较，也不表示正式评估协议已经确定。
- 固定外部预训练图像编码器，构造 global-only 与 global+local 两种特征条件。
- 以 2x2 区域池化作为局部特征候选，先不增加检测器；区域不等于语义部件。
- LR/SVM 使用图片对特征差异；SupCon 在每张图的特征上训练嵌入网络，再做匹配。
- 冻结骨干的轻量 SupCon 属于应用改编，不是端到端复现。训练用投影头与最终用于匹配的可训练表示必须区分，避免丢弃全部学习成果。
- 三算法各自比较两种特征，共六组配置；所有方法使用相同测试图片对和遮挡规则。
- 初始试跑可比较无遮挡与一侧图片遮挡面积 25%。遮挡位置、种子、填充值、训练是否增强仍待固定。
- 同大类不等于外观相似；拟用固定外部全局表示选择困难负例，同时报告普通负例，说明选择机制带来的偏向。
- 指标拟为 FPR、TPR、balanced accuracy，均自行计算；阈值只能使用训练/验证部分确定。

### 各算法共同约束

- 先按商品 ID 划分，再在各划分内部创建图片对；同一商品不得跨训练、验证和测试。
- 外层至少 10 折/重复，内层至少 3 折/重复，手动实现；三算法采用相同外层划分。
- 每算法至少调一个超参数，每个至少三个候选值；边界值经常胜出则扩展范围，不操纵结果强迫中间值胜出。
