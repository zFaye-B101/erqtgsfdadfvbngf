# CNN 特征与 LR 开发小试：三轮结果及交接

## 来源和边界

2026-10-11 用户在 Mac/MPS 终端运行本会话脚本并回传输出；本次只转录、核验数值，没有重新训练。终端脚本尚未整合到 `PythonCode/`。本记录不是 SupCon、正式嵌套 CV 或 Windows 验收结果。

环境沿用用户已报告的 Python 3.12.14、torch 2.14.1、torchvision 0.29.1，ResNet18 `IMAGENET1K_V1`。sklearn 版本未在日志中打印。输入直接读取官方 train 原图，最短边至少 100；不使用官方 test。`weights.transforms()` 后在 224x224 查询张量上遮挡 112x112，归一化后填零（ImageNet 均值色）。参考图片始终使用独立的干净缓存。

冻结 layer4；全局平均池化 512 维，2x2 区域分别 L2 归一化后拼接为 2048 维，全局加局部为 2560 维。图片对取绝对差，训练集拟合 StandardScaler，LR 学习权重，不是固定 50/50 余弦融合。AUC、TPR、FPR由脚本手动计算；StandardScaler 是开发脚本中的库实现，正式 from-scratch 要求需另行核对/整合。

负例为同大类随机不同商品，不是已验证的视觉困难负例。每商品选两张合格图，每锚点一正一负。先隔离商品再配对。

后两轮逐种子结果见 [结果CSV](2026-10-11-lr-tuned-results.csv)、[调参CSV](2026-10-11-lr-tuning.csv)、[选参及阈值CSV](2026-10-11-lr-selections.csv)。CSV来自打印到四位小数的结果，不能恢复逐对分数；从舍入值重算的均值/SD末位可能与原输出不同。选择C依据调参AUC，阈值由同一调参集正例排序确定；选择后不重新拟合模型。

## 扩展范围后的结果

| 条件 | 特征 | AUC均值 | TPR均值 | FPR均值 |
| --- | --- | ---: | ---: | ---: |
| Clean | Global | 0.8548 | 0.8222 | 0.2889 |
| Clean | Global+local | 0.8569 | 0.8194 | 0.2778 |
| Occluded25% | Global | 0.8257 | 0.7583 | 0.3194 |
| Occluded25% | Global+local | 0.8316 | 0.7583 | 0.2639 |

用户输出的配对差 G+L - Global，均值 +/- 样本SD：Clean AUC +0.0021 +/- 0.0208、TPR -0.0028 +/- 0.0411、FPR -0.0111 +/- 0.0394；遮挡 AUC +0.0059 +/- 0.0254、TPR +0.0000 +/- 0.0363、FPR -0.0556 +/- 0.0614。

遮挡FPR在三个种子都下降，但TPR不是每个种子相同：45下降约4.17个百分点，46/47分别上升约1.67/2.50个百分点。不能称作严格的测试集FPR@80%TPR；80%只在干净调参集上校准。只有三个开发重复，未做显著性检验，反复看过该开发评估集，不得再称其为未触碰的最终测试集。

选中的C：Global为0.001/0.001/0.01；G+L为0.0001/0.001/0.001。一次最优在边界，不意味着自动无限扩网格。正式网格仍需满足官方中间值要求，并只依据内层验证调整。

## 交接决定和下一步

- 保留 Global512 基线与 G+L2560 研究对照；局部特征没有被证明无效，也没有被证明稳定优越。
- 小试支持将较小C纳入LR候选，但不能将CNN的C或80%目标阈值直接复制到HSV/HOG正式流程。
- 当前 `PythonCode/` 是传统特征流程，不能拿其48/192维结果代表这份CNN结果。
- CNN从原图出发的小试可以继续；传统流程的填边/JPEG问题可并行处理，不是所有CNN工作的前置阻塞。
- 下一步先协调共用商品折、配对、几何处理/扰动、目标TPR和缓存接口，再把CNN流程整合为正式 `.py`；SupCon仍需实现。正式实验不是继续追调这三个开发种子。
